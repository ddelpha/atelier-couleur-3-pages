# Atelier Couleur — Three-page business website (€299)

Fictional French house painter, using the same identity and five Pexels photos as the €149 and €199 examples. Independent package price, not an upgrade charge.

Exactly three public HTML pages:
- index.html: introduction, service previews, about section, inspiration preview and project CTA.
- services.html: interior/exterior painting, preparation, process and expandable FAQs.
- projets-contact.html: stock inspiration gallery, illustrative service area, project preparation and inactive example contact details.

Static HTML/CSS, no build/dependencies, forms or tracking. Real TEI links point to the website provider. Fictional business, stock imagery and inactive contacts clearly labelled. No testimonials or invented credentials. Search indexing disabled.

Local preview: `python3 -m http.server 8768`.

Palette: cream #f7f3ec, charcoal #2e332f, terracotta #a54f39, sand #e9dece.
